# Glasswipe

Native macOS cleaner (Swift + SwiftUI, Liquid Glass, macOS 26+). Planning is tracked as a wayfinder map in GitHub Issues.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `devendra-nationalwala/glasswipe`, managed with `gh` (use `GH_TOKEN="$PERSONAL_GITHUB_TOKEN"`; the default `gh` login is a work account). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root, ADRs in `docs/adr/`. See `docs/agents/domain.md`.
